# CSEEL Design - School Website Design Portal
Official School Website Design & Template Demo Showcase.
Production Domain: **[https://design.cseel.org](https://design.cseel.org)**

## Features
- **Direct School Web Specialist Portfolio**: High-speed, responsive landing page for Indian CBSE, ICSE, and IB schools.
- **10 Unique Template Demo URLs**:
  - `templates/dps-international.html`
  - `templates/st-xaviers-convent.html`
  - `templates/heritage-global.html`
  - `templates/modern-vidya-mandir.html`
  - `templates/bloom-international.html`
  - `templates/oakridge-campus.html`
  - `templates/apex-senior-school.html`
  - `templates/ryan-global.html`
  - `templates/greenfield-eco.html`
  - `templates/little-angels.html`
- **11th Catalog Request Card**: Directly requests the 50+ templates catalog.
- **Secured Serverless API (`/api/school-website-enquiry`)**:
  - Honeypot anti-spam check
  - IP & device rate limiting
  - SQLi & script injection protections
  - Instant Brevo transactional email delivery & Gmail SMTP fallback
- **Direct Template Claim Flow**: Visiting any demo page automatically selects that school template into the enquiry form.
- **Single-view Offer Modal**: Persisted via browser `localStorage`.
